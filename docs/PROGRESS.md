모든 영화는 H.264 영상과 AAC 오디오를 포함한다. `ffprobe -count_frames`, FFmpeg 전체 디코딩·blackdetect·volumedetect와 Chromium 실제 재생을 함께 사용했다. 포스터는 `pdfinfo`로 A3 단일 페이지, `pdftotext`로 여행 제목과 모든 장소 이름, PNG 헤더로 크기를 확인했다. 시각 검토에서 같은 위치 재방문 라벨 충돌, 다중 SVG ID 충돌, 해안 열차의 지지 구조, 산 장면의 교통수단 표현, 영화/지도 타임라인의 불일치를 수정했다. 서울의 산 장면은 자동차와 보행에 맞춰 재출력했으며 교토 1,800개 프레임의 SVG 해시가 수정 전후 동일함을 확인했다.

- `npm ci`: lockfile 기반 재설치 통과.
- `npm test`: 18개 통과, 실패/스킵 0개. 실제 포스터 출력 API와 독립 HTML 다운로드도 포함.
- `npm run build`: 정적 앱·공유 엔진·HTML 생성기·Node 서버의 생산 패키지 생성 통과.

상세 생성 보고서는 `artifacts/{kyoto,seoul,portrait}/validation.json`, 프레임은 각 폴더의 `contact-sheet.png`, 브라우저 결과는 `artifacts/ui-validation.json`에 있다. 재생성 명령은 README에 정리했다.

## 범위와 비용

하나의 완성된 기본 스타일을 제공한다. 한국어/영어 UI와 가로/세로 영화, 인쇄·공유용 파일을 지원한다. 장소는 2–12개이며 긴 이름과 메모는 화면·포스터에서 줄임 표시하고 전체 원문은 JSON에 유지한다. 직선 연결과 Haversine 거리는 실제 교통 경로·이동거리와 다르다. 방문 시각은 입력한 현지 시각이며 시간대 자동 변환은 하지 않는다. 실제 지형·건축 복원 대신 창작 디오라마를 사용한다.

기본 제품 실행의 유료 API 비용은 없다. CPU·저장 공간과 선택한 호스팅 비용은 별도이며, 개발용 Codex 사용량은 제품 실행 비용과 구분된다. 공개 호스팅과 다중 사용자 계정 서비스, 소셜 플랫폼 자동 게시, 바이럴 성과는 이번 구현 완료와 별개의 항목이다.

## 공개 범위와 환경

GitHub 인증 계정 landfill 및 쓰기 권한을 확인했다. 사용자가 기존 **공개 저장소 landfill/route-film 업로드를 명시적으로 승인**했다. 비밀값·개인 여행·의존성 폴더·대용량 중간 출력은 커밋하지 않는다.

클라우드 재사용 install_script/start_skill 초안을 실제 앱 기준으로 갱신·저장했다. 초안 저장과 환경 게시·새 작업 복원은 별개이며 후자의 성공을 주장하지 않는다.
