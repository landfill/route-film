# Route Film · 제작 Goal

하나의 여행 데이터에서 편집 가능한 아틀라스, 재현 가능한 약 60초 MP4, 인쇄용 포스터를 만든다. 외부 사진·영상·지도 타일·유료 API 없이 끝까지 작동해야 한다.

## 이번 제품의 약속

- 장소 이름, WGS84 좌표, 방문 날짜와 시각, 이동 순서, 교통수단, 메모를 직접 편집한다.
- 같은 데이터·색상·장소 ID·시드를 지도, 영화, 포스터에 사용한다.
- 입력 → 미리보기 → 출력 → 다운로드 → 수정·재출력이 실제로 연결된다.
- 영상의 연출 시간과 여행의 실제 방문 시각을 분리한다.
- 생성 중 진행률, 취소, 실패 설명, 재시도가 제공된다.
- 여행 데이터 저장·복원과 작업 결과 복구를 제공한다.
- 코드·설정·샘플·출처·재생성 방법·실제 검증 결과를 저장소에 남긴다.

## 기본 출력

영화는 60초, 1920×1080, 30fps, H.264/AAC MP4. 세로 공유용 1080×1920도 지원 범위에 둔다. 포스터는 A3(297×420mm) 벡터 SVG/PDF와 300dpi급 PNG. 같은 입력·시드·렌더링 설정은 같은 장면 구성·타이밍을 만든다. 서로 다른 OS 글꼴·인코더 버전까지 동일한 MP4 바이트를 보장하는 의미는 아니다.

## 표현 원칙

위치는 실제 좌표로 투영한다. 연결선은 방문 순서를 나타내는 직선이며 확인된 철도·도로·보행 경로가 아니다. 표시 거리는 Haversine으로 계산한 지점 간 대권거리 합이다. 해안·산·도시는 창작 디오라마로 표현하고 실제 지형 복원과 구분한다. 샘플의 방문 시각·메모·여행 이야기는 창작이다.

지도 API, 예약·결제·길찾기, 사용자 계정, 공개 호스팅, 생성형 모델 API는 이번 기본 제품의 필수 요소가 아니다. 브라우저 하드웨어 인코더가 없어도 CPU 프레임 렌더링과 FFmpeg로 결과물을 만든다.

## 완료 판정

완료 여부는 [PROGRESS.md](PROGRESS.md)의 실행 증거로 판단한다. 도구 설치만으로 완료하지 않는다. 영상·포스터·편집 UI 검증과 GitHub 최종 커밋 확인이 남아 있으면 이를 명시한다. 콘텐츠의 바이럴 성과나 상업적 성과는 구현 완료와 별개의 결과다.
