# A Day Away · 하루를 접어 가져오는 방법

## 작품의 중심

**Logline.** 바다를 보러 떠난 사람은 같은 역으로 돌아온다. 달라진 것은 목적지가 아니라 하루를 받아들이는 속도다.

이 영화의 주인공은 장소 목록이 아니라 여행자의 시선이다. 출발은 좁고 질서 있게, 이동은 앞으로, 바다는 넓고 느리게, 귀환은 가까이 따뜻하게 만든다. 시작과 끝에 같은 좌표를 두어 되돌아오는 선이 감정의 변화를 드러내게 한다. 실제 여행 기록처럼 꾸민 다큐멘터리가 아닌, 실제 장소와 창작 시각·메모로 구성한 샘플 여행이다.

**시각 규칙.** 아이보리 종이, 짙은 청록 잉크, 녹슨 주황의 경로. 화면은 여행 수첩처럼 정밀하게, 장면은 종이 위에 세운 디오라마처럼 깊이를 가진다. 위·경도와 순서는 기능적인 정보이고, 빈 공간과 빛의 이동은 감정을 전달한다. 외부 사진·지도 타일·완성 모델을 사용하지 않는다.

**연출 규칙.** 지도에서는 어디에 있는지 알게 하고, 장소 장면에서는 왜 기억하는지 느끼게 한다. 지도를 확대하는 장면만 반복하지 않는다. 서로 다른 깊이의 절차적 레이어, 열차의 진행, 도시의 창, 물의 리듬, 낮에서 밤으로 바뀌는 색을 사용한다. 원근과 카메라 이동은 코드로 계산한 2D/SVG 연출이며 실측 3D 복원이 아니다.

## 60초 편집 콘티

아래는 기본 교토 샘플의 실제 타임라인을 소수 둘째 자리로 반올림한 편집 설계다. 렌더러는 장소 수·메모 길이·지점 간 거리·전체 길이에 맞춰 구간을 배분하며, 물가 장면은 1.38배의 체류 가중치로 호흡을 길게 둔다. 입력을 바꾼 각 출력의 정확한 타임라인은 해당 작업의 `job.json` → `storyboard`가 기준이며, 미리보기와 파일 출력은 같은 함수를 사용한다.

장면 길이를 변경해도 실제 방문 시간은 그대로 남는다. 10–15초 기술 검증에서는 동일한 구조를 압축해 모든 장면 유형과 출력 경로를 확인한다. 자막은 여행자가 입력한 메모이므로 바꾸면 미리보기·영화·포스터에서 함께 달라진다.

## 서체와 안전 영역

랜드스케이프는 넓은 장면과 명확한 하단 정보로, 포트레이트는 수직적인 장면과 위아래 정보로 재구성한다. 가로 화면을 세로로 늘리지 않는다. 짧은 이름은 크게, 긴 이름·메모는 줄바꿈과 제한된 줄 수로 읽기 좋게 배치한다. 정보가 많은 여행은 전체 원문 JSON을 함께 제공해 시각적 생략과 데이터 손실을 구분한다.

장소명·시각·순서가 우선이며 보조 문구는 시각적 위계를 낮춘다. 한글, 라틴 문자, 숫자와 기호가 같은 출력에서 깨지지 않는지 실제 SVG·PNG·PDF·영상 프레임으로 확인한다. 시각적 품질은 프레임 검사를 통해 판정하며 이 콘티 자체를 구현 완료 증거로 삼지 않는다.

## 두 번째 이야기: 서울의 푸른 시간

궁의 아침 → 낮은 골목 → 도시를 내려다보는 언덕 → 저녁의 하천 → 자정을 넘긴 강변. 첫 여행이 멀리 나갔다 돌아오는 선이라면 두 번째는 익숙한 도시 안에서 시야가 열리는 선이다. 경복궁·북촌·남산서울타워·청계천 동쪽 구간·뚝섬한강공원이라는 다른 좌표와 다음 날의 시각을 사용해 첫 샘플에만 맞춘 장면이 아님을 확인한다. `coast` 계열 장면은 여기서 물가의 창작 표현이며 실제 해안이라고 주장하지 않는다.

## 공유할 이유

공유하는 사람에게는 ‘내 여행을 설명하는 수고를 덜어 주는 60초’, 보는 사람에게는 ‘나도 기록하고 싶은 한 장’이 되어야 한다. 큰 워터마크나 허위 소셜 증거를 넣지 않는다. 세로 영상과 인쇄용 포스터는 같은 여행의 독립적인 공유 형식이다. 출력 후 수정할 수 있고 입력 JSON을 보관할 수 있다는 점이 일회성 장식과의 차이다.

바이럴을 약속하지 않는다. 대신 초반의 방향성, 실제 기억을 담은 메모, 끝까지 이어지는 서사, 읽을 수 있는 텍스트, 완전한 다운로드라는 제작 조건을 확인한다.
